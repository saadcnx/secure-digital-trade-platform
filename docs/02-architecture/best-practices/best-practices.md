# Industry Best Practices (Phase 2)

- **Decide with explicit quality attributes**, not tool preference.
- **Make the simplest option compete** in every ADR.
- **Isolate by blast radius**; design the failure first, then the feature.
- **Keep the critical path short**: only what must be synchronous is synchronous.
- **Give every decision a revisit trigger**, so the architecture can evolve without a rewrite.
- **Prefer reversible decisions**: the ledger-agnostic API is an example.
- **Treat shared components as risk concentrators**, so minimise their authority.
