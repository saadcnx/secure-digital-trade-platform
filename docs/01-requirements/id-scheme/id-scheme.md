# Requirement ID Scheme

Everything is traceable. Use these prefixes consistently across all Phase 1 artifacts and later phases.

| Prefix | Meaning | Example |
|---|---|---|
| `BD-` | Business driver | BD-1 |
| `FR-<DOM>-` | Functional requirement (domain-scoped) | FR-FRD-01 |
| `NFR-` | Non-functional requirement | NFR-01 |
| `REG-` | Regulatory obligation | REG-PCI-3 |
| `SEC-` | Security control | SEC-01 |
| `PRV-` | Privacy requirement | PRV-01 |
| `CON-` | Constraint | CON-01 |
