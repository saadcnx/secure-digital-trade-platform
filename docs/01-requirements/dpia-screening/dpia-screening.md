# DPIA Screening

Large-scale systematic processing combined with automated decisions and cross-border flows almost certainly meets the threshold. Use the EDPB/WP29 high-risk criteria as checklist.

| Criterion | Triggered? | Evidence |
|---|---|---|
| Evaluation or scoring (profiling) | Yes | Fraud scoring |
| Automated decision with significant effect | Yes | Blocks and account closures |
| Systematic monitoring | Yes | Behavioural analytics, IoT tracking |
| Large scale | Yes (assumed) | Global marketplace |
| Matching or combining datasets | Yes | Cross-domain signals |
| Innovative technology | Arguably | ML and ledger |
| Vulnerable subjects | Unlikely | Note as checked |
| Sensitive or special-category data | Not intended | Confirm none inferred |
| Prevents exercising a right or service | Possible | Wrongful blocks |

**Conclusion:** DPIA required (GDPR Art. 35). Begin now with processing description, necessity and proportionality, risks to individuals, mitigations. Complete in Phase 5.

## Open items for Phase 5

- Lawful-basis register finalised with LIA for legitimate interests.
- Transfer impact assessments (TIAs) for cross-region hashed-signal sharing.
